# qazaqsha Quest

qazaqsha Quest — обучающая игра для детей, начинающих изучать казахский язык.

Реализованы стартовый экран и список уроков с названиями, сложностью и отображением прогресса. Игровые задания пока не реализованы. Требования описаны в `specs/001-project-foundation.md` и `specs/002-lesson-system.md`.

## 1. Назначение проекта

Помочь детям делать первые шаги в изучении казахского языка через игру. Обучение должно быть понятным, увлекательным и доступным с телефона.

## 2. Для кого создаётся приложение

Основная аудитория — дети, которые только начинают изучать казахский язык. Интерфейс должен учитывать отсутствие опыта: простые действия, понятные подписи и удобные элементы управления.

Точный возраст детей и язык пояснений пока не определены.

## 3. Основные идеи и возможности

- Изучение казахского языка в игровой форме.
- Простой, яркий и понятный интерфейс.
- Удобное использование на телефоне.
- Постепенное добавление возможностей по отдельно согласованным требованиям.

Конкретные задания, правила игры и учебные материалы ещё предстоит согласовать. Сейчас работающих игровых возможностей нет.

На текущем экране отображаются:

- Название «qazaqsha Quest».
- Описание «Игра для первых шагов в казахском языке».
- Раздел «Уроки» с карточками «Приветствия», «Цвета», «Числа» в этом порядке. У каждой карточки — «Сложность: Начальный», «Прогресс: 0%» и пустая полоса прогресса.
- Сообщение «Учебные задания появятся позже».

Экран оформлен в ярком мультяшном стиле: светлая карточка на бирюзовом фоне, крупный заголовок и жёлтые акценты. Текст переносится по ширине экрана. После перезагрузки отображается тот же экран. Кнопок, переходов и сохранения данных пока нет.

Карточки предназначены для просмотра. Начальные 0% означают, что уроки ещё не пройдены; задания и изменение прогресса пользователем пока отсутствуют. Список и значения заданы в `script.js`, при перезагрузке они загружаются заново. Полоса показывает целый процент от 0 до 100. Если значение отсутствует или некорректно, появляется «Прогресс пока неизвестен» без полосы. При пустом списке видно «Пока нет доступных уроков», при пустом названии — «Урок без названия», при пустом уровне — «Сложность не указана».

## 4. Устройства

Приложение должно быть удобным прежде всего на телефонах.

Страница адаптируется к ширине экрана телефона, планшета и компьютера. Целевые мобильные браузеры — Chrome на Android и Safari на iPhone. В стилях предусмотрены отступы для вырезов экрана; масштабирование пользователем доступно.

Эмуляция мобильных размеров в настольном Chrome проверяется отдельно от реальных устройств. Работа на реальных Android и iPhone и в Safari пока не подтверждена; точный перечень поддерживаемых версий браузеров не определён.

## 5. Технологии

- HTML — разметка страницы в `index.html`.
- CSS — оформление и адаптация к разным экранам в `styles.css`.
- JavaScript — `script.js` подключён с `defer`, содержит данные уроков и построение карточек с прогрессом.
- Markdown — описание проекта и требований.
- Git — история изменений проекта.

Используются обычные HTML, CSS и JavaScript без дополнительных библиотек, фреймворков и сборки. Внешних шрифтов, изображений и сетевых запросов приложения нет. Для текущей страницы сервер и интернет не требуются. Необходимость сервера и способ хранения данных для будущих функций пока не определены.

## 7. Будущие функции

Список будущих функций пока не утверждён. Возможные направления для обсуждения:

- Знакомство с базовыми словами по темам.

## Предположения и открытые вопросы

Текущая страница открывается в браузере и использует HTML, CSS и JavaScript без дополнительных библиотек. Русский язык первого экрана принят для начального этапа; окончательный язык интерфейса ещё предстоит определить.

Нужно уточнить:

- Возраст детей и язык интерфейса и пояснений.
- Содержание уроков «Приветствия», «Цвета», «Числа» и формат игровых заданий.
- Нужны ли озвучка, изображения и другие учебные материалы.
- Нужно ли сохранять прогресс и как он должен храниться.
- Требуется ли работа будущих игровых функций без интернета.
- Какие браузеры и устройства необходимо поддерживать.

## Как запустить локально

1. Открыть папку проекта в проводнике. Если проект скачан архивом, сначала распаковать его целиком.
2. Открыть `index.html` двойным щелчком или через «Открыть с помощью» в браузере. Оставить `styles.css` и `script.js` рядом с ним.
3. Убедиться, что видны название, описание, три урока с начальным прогрессом 0% и сообщение о будущих заданиях.

Установка программ, библиотек, сборка и запуск сервера не нужны. Адрес страницы начинается с `file:///`.

## Как проверить

1. **Содержимое и оформление.** Открыть страницу по инструкции выше. Сверить название проекта, описание и сообщение о будущих заданиях. Проверить порядок уроков «Приветствия», «Цвета», «Числа», уровень «Начальный», 0% и пустую полосу у каждого. Проверить фон, карточки и читаемость текста.
2. **Подключение файлов.** В Chrome открыть F12 → Network («Сеть»), перезагрузить страницу и проверить загрузку `styles.css` и `script.js` без ошибок. Во вкладке Console («Консоль») не должно быть ошибок приложения.
3. **Работа без сети и перезагрузка.** В Network выбрать Offline («Не в сети») и перезагрузить локальную страницу. Оформление, существующие тексты и три урока с 0% должны сохраниться. Временные подстановки из инструкции ниже должны исчезнуть. После проверки вернуть No throttling («Без ограничений»).
4. **Размеры и поворот.** В F12 включить панель устройств и режим Responsive. Последовательно задать ширины 320, 375, 390, 768 и 1280 CSS-пикселей, затем поменять ширину и высоту местами. Текст не обрезается и не перекрывается, горизонтальной прокрутки нет. Вертикальная прокрутка допустима.
5. **Увеличение текста.** На ширине 320 во вкладке Elements («Элементы») выбрать `html` и временно добавить в Styles правило `font-size: 200%`. Основной текст увеличится с 16 до 32px; всё содержимое должно оставаться доступным. Удалить временное правило.
6. **Пустые и длинные значения.** Через Elements временно заменить тексты заголовка и абзацев: сначала на пустую строку, затем на «0», фразу длиной около 300 символов, строку из 100 букв без пробелов и «Ә Ғ Қ Ң Ө Ұ Ү Һ І». На ширине 320 текст не должен создавать горизонтальную прокрутку и наложения. «0» и казахские буквы должны отображаться корректно. Изменения в инспекторе не сохранять в исходные файлы; перезагрузка восстановит исходные тексты.
7. **Реальные телефоны.** При наличии устройств открыть доступный предпросмотр проекта по HTTP в Chrome на Android и Safari на iPhone, проверить две ориентации, масштабирование и отступы у вырезов. Записать устройство, версию браузера и адрес предпросмотра. Открытие файла на компьютере не заменяет эту проверку; настройка хостинга в первый этап не входит.

### Данные уроков и прогресс

Следующие команды выполнять в Console инструментов разработчика на открытой странице проекта, по одному блоку за раз, проверяя результат после каждого. Они временно перестраивают список в браузере и не меняют исходные файлы. Перезагрузка или `renderLessons(lessons)` возвращает исходные три урока с 0%.

1. Проверить три значения прогресса:

```js
renderLessons(lessons.map((lesson, index) => ({
  ...lesson,
  progress: [40, 0, 100][index],
})));
```

Ожидается: у «Приветствия» — 40% и частичное заполнение, у «Цвета» — 0% и пустая полоса, у «Числа» — 100% и полная полоса. В Elements → Accessibility у каждого `progress` проверить роль progressbar, название с названием урока, значение и диапазон 0–100.

2. Проверить пустой список:

```js
renderLessons([]);
```

Ожидается: заголовок «Уроки» и сообщение «Пока нет доступных уроков», без карточек.

3. Проверить пустые поля и неизвестный прогресс:

```js
renderLessons([{ id: 'check', title: '', level: '', progress: undefined }]);
```

Ожидается: «Урок без названия», «Сложность не указана», «Прогресс пока неизвестен», без полосы. Повторить с пробелами вместо пустых названия и уровня. Для прогресса по очереди подставить `''`, `-1`, `101` и `12.5`: результат должен оставаться неизвестным. Затем задать название `'0'` и прогресс `0`: должны появиться название «0», «Прогресс: 0%» и пустая полоса.

4. На ширине 320 проверить длинные названия и казахские буквы:

```js
renderLessons(['Учебный урок '.repeat(25), 'А'.repeat(100), 'Ә Ғ Қ Ң Ө Ұ Ү Һ І']
  .map((title, index) => ({ id: `check-${index}`, title, level: 'Начальный', progress: 100 })));
```

Ожидается: названия видны полностью и переносятся, уровни и прогресс не перекрываются, горизонтальной прокрутки нет. Повторить с увеличением текста до 200% по пункту 5 выше. Перезагрузить страницу и сверить исходные данные.

Игровые сценарии пока не проверяются: заданий ещё нет. Результаты и ограничения проверок основы записаны в `specs/001-project-foundation.md`, списка уроков — в `specs/002-lesson-system.md`. Проверки на реальных устройствах и с программами чтения с экрана отмечаются отдельно от эмуляции и проверки дерева доступности.
